# Pinterest All Pins

Pinterest pin planning workbook and branded product images for Lara Jewels.

- [Download the Pinterest pins workbook](./pinterest_pins_diag_2022.xlsx)
- `branded_batch_diag_creative/`, `branded_batch_duo/`, and `branded_batch_uni/` contain 2,022 images each.
- PNG images are stored with Git LFS.
- The workbook includes Pinterest titles and descriptions, Lara Jewels search links, and image file paths.
